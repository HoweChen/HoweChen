## ⚡ Engineering Philosophy

```text
Make it work.
Make it observable.
Make it scalable.
Make it boring in production.
Then make it beautiful.
```

我相信好的工程不是炫技，而是：

- 出问题时能快速定位
- 流量涨起来时不会慌
- 新人接手时不会哭
- 半夜报警时不是“玄学”
- AI 生成的代码也要过得了 production 的毒打
